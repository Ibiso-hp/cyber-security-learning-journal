# Linux Fundamentals — Learning Log

## Overview

I have been learning the fundamentals of Linux using Kali Linux, focusing on the filesystem, terminal navigation, Bash, and accessing command documentation.

## Topics Covered

### 1. Linux Filesystem and Directories

I learned about the Linux filesystem structure and the purpose of several directories:

- `/` — the root of the filesystem.
- `/home` — contains users' home directories.
- `/bin` — contains essential command binaries on systems where this directory serves that purpose.
- `/lib` — commonly contains essential shared libraries.
- `/mnt` — commonly used as a temporary mount point for filesystems.
- `/media` — commonly used for removable media mount points.

I also learned about directories such as Documents and workspace folders.

### 2. Terminal and Bash

I learned the difference between the terminal and the shell, and was introduced to Bash as a command-line shell used on Linux systems.

I also encountered the terms binaries and scripts and began learning how command-line tools are accessed.

### 3. Navigating the Filesystem

Commands covered:

| Command | Purpose |
|---|---|
| `cd` | Changes the current directory. |
| `cd ..` | Moves up one directory level. |
| `ls` | Lists files and directories. |

These commands helped me understand how to move around the Kali Linux filesystem.

### 4. Command Documentation

I learned that Linux provides manual pages for many commands and tools.

For example:

`man aircrack-ng`

This opens the manual page for Aircrack-ng when the relevant manual is available.

I also encountered command-line help options and learned that command syntax uses different symbols for different purposes.

## Key Takeaways

- Linux organizes files and directories in a hierarchical filesystem.
- The terminal allows interaction with the system through commands.
- Bash interprets commands entered by the user.
- Commands such as `cd` and `ls` are useful for filesystem navigation.
- Manual pages provide information about available commands and tools.
