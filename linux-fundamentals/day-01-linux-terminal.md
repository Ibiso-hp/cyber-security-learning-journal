## Concepts learned

**Operating system:** Software that manages computer hardware and provides services for applications.

**Linux:** An open-source kernel used by operating systems such as Kali Linux.

**Terminal:** A text-based interface for entering commands.

**Shell:** A program that interprets commands entered by the user.

## Commands practised

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory. |
| `whoami` | Displays the current username. |
| `hostname` | Displays the computer's hostname. |
| `date` | Displays the system date and time. |

## Practical exercise

I opened the Kali Linux terminal and ran the four commands individually to observe their outputs.
